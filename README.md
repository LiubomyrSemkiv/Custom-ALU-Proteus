# Specialized 12-bit Calculator (Proteus) 🧮
This repository contains my coursework on Computer Circuitry. It is a specialized microprogrammed calculator designed and simulated in Proteus[cite: 97, 107].

## Project Details
* **Architecture:** Microprogrammed Mealy automaton with separate operational and control units[cite: 106, 107].
* **Components used:** 74LS181 ALU, 6116 RAM, 2732 ROM, 74LS163/169 counters, and 74LS198 shift registers[cite: 109, 110, 111, 114].
* **Function:** Computes the formula Y(i) = (9*X(i) - 3*X(i+1))/16 using 8-bit two's complement binary code and a 12-bit ALU data path to prevent overflow[cite: 117, 132].
